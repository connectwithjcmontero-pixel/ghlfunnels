# HyperFrames

HyperFrames (by HeyGen) makes video from HTML. Use it for ready-made blocks like transitions and social overlays.

- Browse blocks: `npx hyperframes catalog`
- Add one: `npx hyperframes add <name>`
- Health check: `npx hyperframes doctor`

Store HyperFrames compositions and their assets in this folder. Remotion (`src/`) stays the main editor.
