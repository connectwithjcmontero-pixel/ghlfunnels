# Brand

Put these here once:
- **Fonts**: `.ttf`, `.otf` or `.woff2` files (or just the Google Font names)
- **Colors**: hex codes, e.g. `#F5E6D3`, with what each is for (text, accent, background)
- **Logo**: PNG or SVG with a transparent background
- **Guidelines**: anything else (tone, do's and don'ts), as a PDF or notes

Claude reads this folder before every storyboard and copies the fonts and colors into `src/brand.ts`.
Until then, captions use a clean bold sans-serif (Montserrat style) in white.
